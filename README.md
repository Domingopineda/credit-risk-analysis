# Credit Risk Analysis

## Project Overview
Credit risk analysis of **80,000+ loan records** using SQL for data transformation and Tableau for visualization. The analysis identifies income, loan intent, interest rate and credit history as the determining variables in the probability of default.

## Business Problem
Financial institutions need to evaluate borrower risk accurately to minimize loan defaults and price risk correctly.

## Tools Used
- SQL Server
- Tableau
- Excel

## Key Questions
- Do lower-income applicants have higher default rates?
- Which loan purposes carry the highest risk?
- How does interest rate impact default probability?

## Key Findings
- Borrowers with lower income show higher default risk, and the risk increases sharply for borrowers with active loans.
- Loans intended for home improvement show a higher rate of non-compliance.
- Higher interest rates are associated with a higher probability of default — riskier loans are priced with higher rates.
